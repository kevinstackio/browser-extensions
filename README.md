# Browser Extensions

## 项目结构

```text
my-extensions/
├─ apps/                 # 应用项目
├─ .gitignore           # Git 忽略规则
├─ AGENTS.md            # 项目协作规范
├─ LICENSE              # 开源许可证
├─ README.md            # 项目说明
├─ package.json         # 根项目配置与统一命令
├─ pnpm-workspace.yaml  # pnpm 工作区配置
└─ turbo.json           # Turborepo 任务配置
```
